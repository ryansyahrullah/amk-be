# Modul FAT (Finance / Accounting)

Dokumentasikan endpoint seperti:
- `GET /fat/jurnal-umum`
- `POST /fat/jurnal-umum`
- `GET /fat/jurnal-umum/:id`

Sertakan:
- Contoh request / response
- Aturan siapa yang boleh create (admin_fat), siapa yang hanya boleh read (direktur, superadmin).
