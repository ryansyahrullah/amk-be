# Modul AUTH

Dokumen ini akan menjelaskan endpoint-endpoint AUTH, misalnya:
- `POST /auth/login`
- `POST /auth/users`
- `POST /auth/forgot-password`
- `POST /auth/reset-password`
- Endpoint untuk manajemen role dan permission.

Untuk setiap endpoint, tuliskan:
- Deskripsi singkat
- Request body (contoh JSON)
- Response (contoh JSON)
- Catatan khusus (permission, role yang boleh akses, dsb).
