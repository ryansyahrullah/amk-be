# Modul HC-GS

Berisi dokumentasi endpoint yang berkaitan dengan pegawai, misalnya:
- `GET /hcgs/pegawai/me`
- (Nanti) endpoint CRUD data pegawai untuk admin HC-GS.

Tuliskan:
- Cara kerja autentikasi (wajib Bearer token)
- Struktur response data pegawai
- Role apa saja yang boleh mengakses.
